# Phoenix of Stained Glass

A phoenix built from stained glass rises over a dark city at night. Its wings
are panels of ruby, amber, and sapphire that catch the moonlight while embers
drift through the air below. The glow of the wings against the sleeping
rooftops is the whole point of the picture.

This entry is a single image for the coolest-art bounty. The program does one
thing: it copies the bundled artwork to `/output/entry.png`, checking first
that the file is a valid JPEG under the 1 MiB size limit and verifying the
copy byte for byte.
